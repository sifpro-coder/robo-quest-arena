# CFI ROBOT V7.4.1 — Jeux simplifiés
Pré-requis : V7.4 déjà déployée. Sauvegarder le dépôt, extraire le ZIP, puis remplacer ensemble les 8 fichiers HTML/JS dans le dépôt GitHub (branche main). Ne pas remplacer les autres fichiers, en particulier challenge-server.js, academy.html et les banques de questions. Aucun changement SQL. Si vous avez modifié ces fichiers depuis V7.4, fusionner les modifications au lieu de les écraser.

Accueil : le champ de code universel accepte les huit jeux. Dans /arena, une carte par jeu ouvre deux choix : Jouer seul / Avec mes amis. En solo les six jeux locaux gardent leurs moteurs existants. Snake et Battle utilisent désormais une session privée, démarrée automatiquement après validation des paramètres, sans adversaires IA ; pas de code visible ni accessible par la recherche universelle. En mode amis : choisir les paramètres et Générer le code, puis lancer la partie dans le lobby. Les invités saisissent uniquement le code depuis l'accueil. Les modes Démo et Premium de Battle sont conservés. Les droits des comptes et données existantes ne changent pas.

Tests locaux : syntaxe JS, Chromium avec HTML chargé en mémoire : 8 cartes, deux choix, lancement solo Maze et retour, configuration Quiz entre amis. Serveur Node avec banque de questions embarquée et données Academy locales : deux clients WebSocket, Snake/Battle solo démarrage automatique, refus d'un second joueur, absence du code solo dans le routeur public, et connexion multijoueur ; vérification du code universel pour Maze, Debug, Memory et Circuit. Le navigateur interdit les connexions HTTP locales : pas de test intégral navigateur-serveur ni sur Render/Supabase de production. Vérifier /health version 7.4.1 après déploiement et essayer depuis deux téléphones. Un déploiement interrompt les parties en cours.
