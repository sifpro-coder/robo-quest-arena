# CFI V7.4 – Live Challenges + Mon espace
Pré-requis: V7.3 Code Universel et Academy V7.2. Sauvegarder le dépôt. Dans un seul commit GitHub, ajouter challenge.html et challenge-server.js, remplacer index.html, server.js et academy.html. Conserver tous les autres fichiers. Aucune migration SQL. Le serveur est basé sur V7.3; si vous avez modifié le serveur après V7.3, fusionner au lieu d'écraser.

Les quatre nouveaux modes Live (Maze, Debug, Memory, Circuit) sont accessibles depuis Arena à côté de la version Solo existante. Le créateur définit 2–10 joueurs et 1–5 minutes, génère un code, attend au moins 2 joueurs et lance la partie. Le code universel fonctionne depuis l'accueil; les parties et leurs classements en direct sont en mémoire du serveur. Chaque joueur résout ses propres défis; scores validés côté serveur. Un lien de partie peut être copié. Le mode Maze est une course de navigation individuelle sur des grilles, pas un déplacement partagé sur un plateau commun. Les questions sont en français. Les joueurs peuvent rejoindre la salle avant le départ; le même navigateur peut se reconnecter via son jeton de session. Ne pas déployer pendant une partie.

Mon espace est accessible via Academy > Mon espace ou /academy?view=account: progression, droits acquis (pas un relevé de paiements), certificat ESP32 PRO existant, inventaire Battle du compte. L'inventaire nécessite la table V5.6 déjà installée. Aucun nouveau XP permanent, historique des matchs, classement mondial ni nouveau certificat n'est créé dans cette version. Les comptes et droits existants sont inchangés.

Tests: node --check pour les scripts JS et HTML; serveur local avec deux vrais clients WebSocket par nouveau jeu, résolution HTTP du code, démarrage, action valide, points, fin de partie. Test d'accès anonyme à l'inventaire (401). Banque Arena de test vide et fichiers Academy locaux; aucune connexion Supabase réelle, aucun test visuel navigateur ni test de charge. Tester après déploiement avec deux téléphones et un compte étudiant. Vérifier /health (version 7.4.0). Les anciennes routes sont conservées mais les anciennes parties n'ont pas été retestées dans ce cycle.
